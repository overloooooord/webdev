So, jumping into the Ubisoft Ticket Manager... to be completely honest, a lot of things aren't fully working yet and we definitely need to do a lot of retesting to iron out the bugs, but I want to show you what we have actually managed to get done so far. Basically, the main goal of this project is to automate the whole account recovery process because doing it manually is a nightmare, especially with all the rate limits, cloudflare blocks, and repetitive logins. We built a fast frontend using Vite and Vanilla JS connected to a FastAPI Python backend, and everything saves in real-time to a local SQLite database using WAL mode, so we don't lose data if the system crashes. Right now, one of the coolest things that is actually implemented is the automated browser login. Instead of dealing with Chrome proxy authorization issues, we use Playwright combined with a stealth Camoufox browser. When you click the view profile icon, it launches the browser, injects the existing session cookies, and if the session is dead, it automatically types in the email and password to log you back in. We also added a settings panel where you can toggle four different captcha solving methods depending on what gets blocked, and we integrated a non-Western AI called Yunwu to help generate replies to support tickets without automatically sending them. Like I said, there are still issues and things breaking, and over the next three days my plan is to do some heavy retesting, fix those remaining bugs, get the IMAP email verification working automatically for 2FA, and just make sure the whole bulk CSV import and ticket creation flow is actually stable under load. So yeah, that's where we are at right now, and I'd love to hear your thoughts or any feedback you guys have.
